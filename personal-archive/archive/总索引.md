# 个人档案 · 总索引

本档案是**给人看**的那一层：身份、工作方式、固定规范与关键决策。
供智能体读取的那一层在记忆库（`shared-agent-memory`）——两处**分开存储、互不镜像**。

> 本文件是**模板骨架**，用于新档案起步。若你的真档案已存在，请用
> `bash install.sh --update --link-archive "<真档案路径>"` 把各 agent 的 `archive/`
> 统一软链过去，而不是在这里填内容。

## 板块结构

板块目录名即主题，篇目文件名即主题（不写数字编号前缀）：

| 目录 | 放什么 |
|---|---|
| `画像/` | 我是谁：身份、背景、资源条件、目标 |
| `日志/` | 发生过的值得记的事（文件名带日期前缀） |
| `规范/` | 固定规则：保留要求、界面与交付、隔离与放行 |
| `决策/` | 拍过板的决定：为什么这么定、备选与取舍（文件名带日期前缀） |
| `财务/` | 收支概览与索引（原始账单归档在档案之外，档内只留概览与索引） |

> 规则：**一模块一篇**；新增内容按主题归入对应板块；板块可扩展，新板块直接建目录并登记到本文件。

## 维护约定

1. **只增不删**：过时内容不直接抹掉，标为「已作废」并注明替代项。
2. **不出现机器绝对路径**：用相对路径或「日期 + 主题」。
3. **工具品牌可正常出现**：档案是人的笔记，「用某工具做了某事」是事实陈述，不违规。
4. **最小必要脱敏**：证件号、银行卡号、完整手机号、详细住址、凭据不落正文。
5. **与记忆库的关系**：档案是「人读版」，记忆库是「机读版」；两处分开存储、互不镜像，
   只有「对智能体有用」的内容才允许单向放行过去。
